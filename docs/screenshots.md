# Capture provenance

`src/data/screenshot-assets.json` records dimensions, byte counts, SHA-256 and
original timestamps. `scripts/optimize-screenshots.mjs` verifies original PNG
hashes, then exports responsive WebPs without altering the originals.

`desktop-jit-reports-20261117` is the dated November 17 real-stack JIT acceptance
capture from Desktop source around `f6a1ad00` / `e6232233`, Server `6617981d` and
that run's Palpo/Pasion. It shows synthetic test accounts and six decrypted
Agent replies after offline delivery/restart. The model boundary is a
deterministic Codex-protocol subprocess. It is not paid inference, a capture of
current main or proof of all ADR-0013 paths. The original image was visually
checked before adding it. No credential, personal account or room secret appears.

The six September captures are archived in the Media page with their original
product labels. Retired Fleet/resource-allocation and Palpo companion screens
are never presented as current Server/Desktop UI. There is no current standalone
Palpo or Server capture in this gallery. Conceptual diagrams are labeled as such.

New audit screenshots and fixture profiles remain private under ignored `.run/`.
The enlarged viewer, original link, actual-size mode, error recovery and keyboard
focus return are checked in both languages and narrow/wide viewports.
