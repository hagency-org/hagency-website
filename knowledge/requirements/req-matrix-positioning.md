## Source

The operator requested an introduction to Matrix, its advantages over centralized
messaging, the open-source WeChat positioning, agents with explicitly granted
human-equivalent privileges, and federation. The existing English/Chinese scope
continues to apply.

## Requirements

- Add a discoverable Matrix introduction in both languages and on the homepage.
- Position Hagency as an open-source, agent-native alternative to WeChat for
  communication and collaboration, without claiming feature parity or affiliation.
- Explain federation, independent homeservers, shared rooms, client choice, and
  the operational tradeoffs compared with centralized messaging.
- Explain agents' own identities and the same room permission model as humans.
  Granted room authority does not automatically grant runtime execution authority.
- Use primary Matrix sources and clearly illustrative interactive explanations.
- Preserve existing routes, visual design, localized navigation, and local preview.
